它到底做了什么

三步，全部在你自己的电脑上完成。

  1. 读名单

    解析 CSV：姓名、邮箱、职称、院系、研究方向。没有邮箱的行跳过，重复的邮箱只发一次。

  2. 单独写

    用你选的模型，结合你的背景和这位教授的方向写一封信；格式校验不过就重写，最多三次。

  3. 逐封发

    经你的 SMTP 发出，附件带上简历；可暂停、可停止，重跑自动跳过已发的。

为什么不是群发

每封都不同

第 3–5 段围绕该教授的研究方向重写，提示词明确禁止只替换关键词。

只用真事实

模型只能使用「申请人背景」里写的内容，成绩、论文、奖项、联系方式都不会被编造。

固定格式

称呼 → 自我介绍 → 经历 → 提问 → 此致/敬礼 → 署名，中英各一套。

实时进度

已发/剩余/失败、用时、预计剩余、Token 与预估费用，逐封日志。

不会重复

发送记录写在 runs/ 里，中断后重跑从没发过的地方继续。

凭据不落盘

授权码与 API Key 只存在内存，程序一关就没了；只监听 127.0.0.1。

快速开始

需要 Python 3.9+，不需要安装任何第三方库。

# 克隆仓库
git clone https://github.com/<your-name>/professor-outreach.git
cd professor-outreach

# 启动，然后打开 http://127.0.0.1:8765
python app.py

Windows 也可以直接双击 start.bat。第一次使用建议先选「演示模式」，点「预览第一封」看格式。

几个常见问题

它会自动替我发邮件吗？

不会。所有邮件都在你本机生成，由你点「开始发送」才发出，发送前还有一次确认。

我的邮箱密码会被上传吗？

不会。授权码只存在内存里，用于这一次连接；程序关闭即消失，也不写日志。

能放在网上给所有人用吗？

不建议。别人的邮箱授权码会经过你的服务器。让每个人在自己电脑上运行更安全。

支持哪些模型和邮箱？

DeepSeek、OpenAI、Kimi、SiliconFlow 或任意 OpenAI 兼容接口；QQ、Gmail、Outlook、163、126 或自定义 SMTP。
